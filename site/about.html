An idea should not become a surprise bill

AI makes it possible to build software for the way you actually think and work. But getting an idea into everyday use can still mean learning several platforms, connecting accounts, and paying for tools you do not yet understand.

Unforge began with that frustration: CI minutes and cloud compute costs that were easy to start using and harder to see coming. Saving code, checking a change, and keeping a recovery copy should be understandable parts of building something useful.

The aim is a simpler relationship with your software: see where it lives, understand what an action does, choose which services are worth paying for, and keep the ability to leave.

Built by someone who needed it

Unforge was created by Viiberr1128, with AI-assisted development using OpenAI’s Codex. It is an independent open-source project, shaped by the experience of building useful apps while still learning how development works.

Codex helped with the building. That is not a guarantee. Read the source and the guide. Unforge is not affiliated with or endorsed by OpenAI, GitHub, Microsoft, Apple, or Google.

Built for humans. Owned by you.

Your projects should be ordinary files with portable Git history. You should be able to use your own coding agent, keep backups in storage you control, and change tools without asking permission to take your work with you.

For beginners, that means explaining the consequence of an action before burying it in technical language. For experienced builders, it means a system that can be inspected, repaired, and used with other tools. For everyone, it means honest boundaries around cost and recovery.

Unforge itself is free and MIT licensed. Providers you choose can still charge for AI, hosting, or storage. Making those choices visible is part of the goal.

Get Unforge without GitHub

The job is to make GitHub obsolete for people who want to own their software workflow. Download the Mac app or the source from this site. You do not need a GitHub account to get Unforge, run it, or ship an app. A public source copy exists so people can inspect it. Your apps run, check, and publish from your Mac.

Version 0.3.1 is a working alpha for local projects, checks, optional Codex proposals, and encrypted workspace recovery. It does not yet replace every team feature, hosted database backup, or billing dashboard. It does replace clone, pull requests, Actions, and Pages for an app you own.

Trust what you can check: the code, a backup you actually restored, and whether a fix solved a real problem. Read the security policy and the installation and recovery guide before depending on the alpha for important work.

Help shape what comes next

Bring a confusing workflow, a reproducible bug, a better explanation, or a change to the code. You do not need to be an experienced developer to help make the product easier to use.
