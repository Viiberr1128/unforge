Not another AI coding subscription.

AI can make an app quickly. Keeping the version that worked, understanding what changed, moving between coding tools, and recovering after a lost computer are still your problem.

Unforge is the ownership layer around that work. Your projects remain ordinary Git repositories. Optional Codex and Subscription Fleet tools work on isolated proposals using accounts already installed on your computer. Unforge accepts nothing until you review it.

A real disposable workspace

A useful change. A saved version. A way back.

This walkthrough uses the actual local app with example data created for the recording. It shows the product interface and completed recovery evidence; it does not claim that an AI provider, deployment, or external account was tested.

One ownership loop.

  1. 01

    Bring the project home

    Create one, import portable Git history, or copy a local app without modifying the original.

  2. 02

    Make changes separately

    Work in a Git lane yourself or ask an installed coding agent for a bounded proposal from the exact saved version.

  3. 03

    Review before accepting

    See the changed files, diff, checks, and reviewer concerns. Saving a version is a separate choice.

  4. 04

    Prove you can recover

    Keep encrypted recovery points on storage you choose and restore into a separate workspace.
